# 战斗人物模板生成规范 V0.1

日期：2026-09-02
状态：已通过 A1 真人试玩验收；正式量产前仍需人工修绘与授权确认

## 目标

为卡牌战斗制作少量可复用的全身战场人物模板。模板需要有接近轻度 3D 卡通手办的体积感，以大色块、圆润体块和低纹理密度保证小尺寸可读；不制作真实 3D 模型，也不为每个普通单位单独画角色。

## 第一批模板

1. 义军步兵：长枪、粗布短褐、绳带与零散错配皮护具、深青和朱砂点色；禁止制式胸甲。
2. 官军步兵：刀盾或枪盾、规整札甲、冷灰与暗朱砂阵营色。
3. 弓兵：敌我分别制作；完整弓身、箭袋与拉弓/搭箭剪影。义军用粗布和自备弓箭，官军用规整短甲。
4. 骑兵：人马全身、枪或刀完整入画，马蹄落地关系清楚；义军使用粗布骑手、绳革马具，不配人马制式甲。
5. 重甲/Boss：更大的肩线、盔甲量感和尺寸等级，不靠发光特效区分。

## 通用生成提示词

> Full-body 2D game combat standee, fictional ancient Chinese military archetype, compact near-frontal three-quarter battle-ready pose, complete head, simple weapon and both feet visible, strong readable silhouette at small size, simplified chunky proportions, large clean color masses, softly rounded 2.5D sculptural volume, restrained mobile-game character detail, teal-green palette with one muted cinnabar accent, simple historically plausible cloth and a few broad lamellar plates, subtle contact shadow, true transparent alpha RGBA PNG. No background, no frame, no text, no logo, no checkerboard, no cropped body, no photorealism, no fantasy glow, no ornate gold, no famous-character likeness, no dense armor plates, no fabric microtexture.

每个兵种只替换武器、甲胄、姿态和阵营色描述；镜头、明暗、线稿粗细、比例与透明底要求保持不变。

## 本轮提示词变体与绑定

所有变体均使用义军步兵 V0.2 作为风格与实际显示尺度参考，采用 ImageGen `stylized-concept` 模式；共同要求为全身、完整兵器、低细节大体块、柔和 2.5D 明暗、透明背景、无文字/边框/著名人物身份。差异部分如下：

| 表现 ID | 造型提示词差异 | 当前绑定 |
|---|---|---|
| `combatant.rebel.infantry` | 深青粗布短褐、补丁裤、绳带、少量错配皮护具、长枪 | 周靖及步兵占优的义军 |
| `combatant.government.infantry` | 暗朱砂与炭灰规整宽甲、圆盾、短刀 | 普通步兵占优的官军 |
| `combatant.rebel.archer` | 深青粗布、补丁裤、绳带、自备木弓与旧箭袋 | 韩月及弓兵占优的义军 |
| `combatant.government.archer` | 青灰规整短甲、完整弓身、统一箭袋 | 弓兵占优的官军 |
| `combatant.rebel.cavalry` | 粗布骑手、完整棕马、绳革马具、长枪，无人马制式甲 | 赵烈及骑兵占优的义军 |
| `combatant.government.heavy` | 宽肩重甲、炭灰与暗朱砂、大型长柄刀、不使用发光 | 贺巍、严成 |

ImageGen 原始输出若将棋盘格烘焙进 RGB，不直接入库。本轮四张新增图先经色键透明后处理输出 RGBA，再检查 Alpha 范围、Godot 导入结果和战斗场景边缘；该后处理只修复背景，不改变人物构图或战斗逻辑。

## 交付检查

- 文件为 RGBA PNG 且 `hasAlpha: yes`。
- 头顶、武器末端、马匹与脚部不得裁断。
- 人物面对战场中央；翻转后兵器握持与服装结构不能产生明显错误。
- 缩至战场实际槽位后，兵种轮廓仍可在 2 秒内识别。
- 接地阴影只服务落地感，不得形成不透明底板。
- AI 输出只作中间稿；正式入库前完成人工修绘、授权与风格一致性签字。

- 六个表现 ID 已按“低细节、大色块、圆润体块”接入；显示槽位统一由早期 254×208 缩至 214×176，可用于 A1 布局、交互和兵种辨识验证。

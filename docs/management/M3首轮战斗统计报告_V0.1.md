# M3 首轮战斗统计报告 V0.1

## 结论先行

M3-05 首轮固定策略矩阵已完成：三名武将对八名正式敌人，各运行 Seed 1～20，共480场。全部战斗可复现，455场胜利、0场失败、25场达到20回合统计上限；兵力胜利379场，士气胜利76场。

当前数值没有同时满足“普通3～5回合、精英4～7回合、Boss 6～10回合”的统一目标。24个 Build×敌人组合中只有8个组合的平均回合位于对应区间。主要偏离不是单纯的敌人血量问题，而是三套 Build 输出跨度过大：赵烈对严成平均5.60回合，韩月14.55回合，周靖20场全部达到20回合上限。因此本报告不修改任何【原型暂定】参数，等待先确认统一回合目标是否必须适用于每套 Build。

## 统计口径

- 固定内容版本：Manifest `0.4.0-m3-boss`。
- 固定样本：赵烈、周靖、韩月 × 五普通、两精英、严成 × Seed 1～20。
- 固定策略：只读取公开 Intent、当前手牌、行动力和公开战斗状态；不读取未来抽牌、敌方后续随机数或隐藏信息。
- 策略身份：赵烈优先免费士气铺垫与连击；周靖只在有护甲输出牌或面对公开攻击时组甲；韩月优先箭阵、破防和多段攻击。
- 单场上限：20回合。超时场以20回合计入“封顶平均回合”，不伪装成胜利。
- `W-D-T` 分别表示胜利、失败、超时；“兵/士”表示兵力胜利与士气胜利数量。
- 目标判定：每个 Build×敌人的20场平均回合与敌人层级目标比较。该策略是可复现基准，不代表真人最优操作或最终胜率。

## 已证实与尚未证实

已证实：三套策略都能触发各自武将天赋；兵力和士气两种胜利都在矩阵中出现；当前普通敌人没有造成自动策略败局；相同输入会复现完整统计行；非法武将、敌人、回合上限和 Boss 修正请求会明确失败。

尚未证实：真人玩家的最优回合数、不同熟练度下的胜率、卡牌升级后的强度、远征跨战损耗，以及三项 Boss 战略削弱后的完整路线收益。这些不应由本轮固定策略数据替代。

## 下一步需要确认

1. 3～5 / 4～7 / 6～10 是否要求三套 Build 的每个敌人组合都大体满足，还是只要求同层级整体中位体验满足。
2. 若保持统一目标，首轮应优先提高周靖主动输出效率，并抑制赵烈对高护甲敌人的士气速胜；不能只统一增加敌人兵力，否则会同时放大韩月和周靖的偏慢。
3. 数值调整后必须用同一480场矩阵复跑，并将修改前后结果并列记录。

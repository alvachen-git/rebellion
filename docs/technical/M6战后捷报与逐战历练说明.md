# M6 战后捷报与逐战历练说明

## 交付范围

M6-04G 在每场胜利与下一阶段之间加入可保存恢复的 `combat_report`：

```text
战斗胜利 → 战后捷报 → 卡牌奖励（如有）→ 远征地图
Boss胜利 → 大捷战报 → 远征最终结算 → 主城
```

撤退与失败不创建胜利战报，继续直接进入远征终报。战报数据由 `ExpeditionRunState` 生成，UI只展示权威结果，不重新计算经验、兵损、士气或奖励。

## 逐战经验

经验配置集中在 `prototype_general_progression.json` 的 `victory_experience`：普通、战略、财富和袭商为15，精英为25，Boss为30。V4任一直线路径的五场必战合计100；最多两次袭商可额外获得30。

远征保存出发等级/经验、累计经验和逐战流水。最终结算通过显式 `experience_gained` 提交真实累计值；成功、撤退和失败均保留已赢得经验，武将永久死亡时由长期成长服务归零。既有 `experience_by_outcome` 只为旧结算请求提供兼容回退。

## 事务与恢复

- 战斗结果、节点完成、未入库奖励、逐战经验与待处理战报在一次自动保存事务中提交。
- 战报以稳定 `report_id` 与 `battle_id` 绑定已结算战斗；重复结果、重复确认和过期战报均不能重复获益。
- 确认战报再次自动保存；保存失败恢复到未确认状态。
- Save V7 为新活动远征保存战报与经验流水。V6活动远征从已有胜利解析流水重建经验，不重播历史战报；旧待结算请求继续沿用结果经验。
- 严格恢复校验逐战经验合计、战报引用、确认 action ID 与历史流水的一致性。

## 玩家反馈

战报展示敌军、胜利标题、武将、经验条、回城升级预告、真实兵力/士气变化、本场奖励、战利品袋总量和路线进度。未入库奖励明确提示远征失败会丢失；Boss使用“大捷”标题并引导至远征总报。常规动画约一秒依次显示历练、奖励和继续操作，减少动态效果时立即展示最终值。

## 验证结果

- M6-04G专项：79通过，0失败。
- M6 UI专项：84通过，0失败；覆盖普通战报、Boss大捷、升级预告、奖励前阶段、1280×720可达性及减少动态效果。
- 完整串行回归：25套、4202通过、0失败。
- 严格日志扫描：无解析错误、无无效调用、无未处理异常、无测试失败、无非白名单ERROR。
- 图形复核：1600×900普通战报与1280×720 Boss大捷均无裁切、重叠或不可达操作。

本批未调整卡牌、敌人、Boss或资源奖励平衡，也未增加评级、无伤奖励、装备和音效。经验数值与表现节奏继续标记为【原型暂定】，交由M6-05真人试玩判断。

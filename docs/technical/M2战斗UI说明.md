# M2 战斗 UI 说明

## 当前状态

M2 最小战斗 UI 已接入 M1 CombatController。所有卡牌、武将和敌人仍为 `development_only` 验证内容，不代表 M3 正式规格。

## 视觉与布局

- 深墨军阵背景、旧纸/青铜强调色和原创程序绘制占位军势。
- 信息层级参考卡牌 Roguelike 的成熟做法，但未使用或复制其他游戏资产。
- Intent 位于战场上方；敌军与我军分据右上、左下；手牌是唯一主要卡片区。
- 1600×900 为设计画布，使用 `canvas_items` 等比适配 1280×720。

## 可操作流程

- 悬停卡牌：卡牌上抬并显示预计伤害或不可用原因。
- 点击卡牌：通过 CombatController 结算，刷新行动力、双方状态和手牌。
- 结束回合：弃置剩余手牌、执行公开 Intent、进入下一回合。
- 撤军：先显示完整风险确认，再进入独立撤退结果。
- 胜利/撤退结果可以重新开始当前原型战。

## 玩家试玩重点

1. 视线是否自然先看到敌方 Intent，再看到双方状态和手牌。
2. 1280×720 下中文卡牌内容是否仍可读。
3. 预计伤害、不可用原因和行动力变化是否足够明确。
4. 出牌、结束回合、撤退确认和结果重开是否顺手。
5. 军阵氛围是否合适，或需要更强调人物立绘。

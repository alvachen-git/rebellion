# M3 战斗运行机制说明

## 武将请求

`GeneralCombatRequestBuilder` 将武将定义转换为 CombatRequest，携带战斗属性、兵种构成、天赋 ID 和20张初始牌组。CombatController 会校验天赋存在且确属该武将；错误归属不会进入战斗。

## 天赋时序

- 韩月【穿阵】：每回合第一张带 `attack + archery` 标签的牌，在卡牌效果前使敌军防御-4。
- 周靖【铁壁】：每回合第一次由卡牌获得护甲后，立即额外获得40护甲；天赋自身护甲不会递归触发。
- 赵烈【陷阵】：每回合第3张攻击牌的卡牌效果结束后返还1行动力，每回合最多一次。

每个触发都会写入 `talent_triggered` 事件；回合上限记录随玩家新回合重置。

## 新效果

- `DealDamageFromArmor`：按当前护甲形成基础威力，可配置结算后是否清空护甲。
- `ConvertArmorToDamage`：先按比例消耗护甲，再按消耗量形成基础威力。
- `RetaliateOnDamage`：记录有限次数的反击；敌军兵力攻击完成且玩家仍存活时触发。
- `PrepareTaggedAttack`：只由匹配标签的攻击牌消耗，倍率作用于该牌的每个伤害段。
- `RestoreTroops`：恢复兵力，但不超过本场最大兵力。

卡牌预计伤害使用状态副本顺序模拟，不修改真实战斗状态；韩月预破防、卡牌内破防、条件追加伤害、敌方护甲逐段吸收、己方护甲来源和箭阵倍率均与实际伤害共用 DamageCalculator。

## 固定 Seed 身份回合

| 武将 | Seed | 核心回合 |
|---|---:|---|
| 赵烈 | 15 | 轻骑袭扰 → 猛攻 → 独胆破阵，触发第3张攻击返行动力 |
| 周靖 | 10 | 盾阵触发铁壁 → 后发制人，以115护甲形成并保留输出资源 |
| 韩月 | 4 | 箭阵待发 → 连弩，穿阵先破防且倍率作用于三段攻击 |

这些 Seed 是身份回归证据，不是平衡结论；回合数与胜率在 M3-05 统计。

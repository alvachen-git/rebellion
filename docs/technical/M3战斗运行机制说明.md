# M3 战斗运行机制说明

## 武将请求

`GeneralCombatRequestBuilder` 将武将定义转换为 CombatRequest，携带战斗属性、兵种构成、天赋 ID 和20张初始牌组。CombatController 会校验天赋存在且确属该武将；错误归属不会进入战斗。

## 天赋时序

- 韩月【穿阵】：每回合第一张带 `attack + archery` 标签的牌，在卡牌效果前使敌军防御-4。
- 周靖【铁壁】：每回合第一次由卡牌获得护甲后，立即额外获得40护甲；天赋自身护甲不会递归触发。
- 赵烈【陷阵】：每回合第3张攻击牌的卡牌效果结束后返还1行动力，每回合最多一次。

每个触发都会写入 `talent_triggered` 事件；回合上限记录随玩家新回合重置。

## 新效果

- `DealDamageFromArmor`：按当前护甲形成基础威力，可配置结算后是否清空护甲。
- `ConvertArmorToDamage`：先按比例消耗护甲，再按消耗量形成基础威力。
- `RetaliateOnDamage`：记录有限次数的反击；敌军兵力攻击完成且玩家仍存活时触发。
- `PrepareTaggedAttack`：只由匹配标签的攻击牌消耗，倍率作用于该牌的每个伤害段。
- `RestoreTroops`：恢复兵力，但不超过本场最大兵力。

卡牌预计伤害使用状态副本顺序模拟，不修改真实战斗状态；韩月预破防、卡牌内破防、条件追加伤害、敌方护甲逐段吸收、己方护甲来源和箭阵倍率均与实际伤害共用 DamageCalculator。

## 固定 Seed 身份回合

| 武将 | Seed | 核心回合 |
|---|---:|---|
| 赵烈 | 15 | 轻骑袭扰 → 猛攻 → 独胆破阵，触发第3张攻击返行动力 |
| 周靖 | 10 | 盾阵触发铁壁 → 后发制人，以115护甲形成并保留输出资源 |
| 韩月 | 4 | 箭阵待发 → 连弩，穿阵先破防且倍率作用于三段攻击 |

这些 Seed 是身份回归证据，不是平衡结论；回合数与胜率在 M3-05 统计。

## 敌人天赋与 Intent 拦截

- 高武【军纪严整】：`ModifyMorale` 由玩家作用于敌军时，在每个玩家回合首次损失前读取 `ScaleIncomingMorale`；7点损失按0.5向下取整为3点，随后同回合正常结算。触发写入 `enemy_talent_triggered`。
- 贺巍【黑甲】：仅追踪开战时的180点初始护甲。玩家伤害首次将其打至0时登记一次战斗级触发，当前已公开 Intent 不变；下一次 Intent 选择临时排除 `defend`，消费后立刻恢复完整技能池。
- 回合开始的护甲自然清除会关闭“初始护甲仍有效”标记，后来技能获得的护甲即使被打穿也不会补触发【黑甲】。
- `EnemyIntentPlanner` 仍只读取公开双方状态、技能条件、冷却、权重和注入 Seed；受控排除列表不会读取手牌，也不会永久修改敌人定义。

## 严成阶段与强制行动队列

- 【死守孤城】以玩家伤害前后的敌军兵力比例判断首次跨线：从50%或以上降到50%以下才触发，恰好50%不触发，敌军已被击破时不触发。
- 触发时立即获得配置的护甲并记录第二阶段，但当前已经公开的 Intent 保持不变；【固守城池】加入强制行动队列，供下一次敌方行动使用。
- 【求援烽火】本回合不造成伤害，只将【援军夹击】加入同一个队列。队列采用先进先出；消费强制行动时不会消耗其他一次性 Intent 排除条件。
- `queued_only` 技能不参与普通权重抽取；队列耗尽后，`EnemyIntentPlanner` 自动恢复完整普通候选池。

## Boss 战前修正

`BossModifierApplier` 在 CombatController 建立状态前验证并复制敌人/天赋定义，再按军械库、烽火台、粮仓的固定顺序应用请求中的 `boss_modifiers`。每项数值与被移除技能 ID 都读取严成内容定义，应用过程不修改 ContentRegistry 中的共享对象。

- 军械库：只降低初始防御、固守护甲和两种阶段护甲。
- 烽火台：只降低初始士气，并移除求援及援军强制技能。
- 粮仓：只移除据城整军。

Combat 只消费这三个布尔输入，不读取 Campaign 或地图状态。非法键、非布尔值、非 Boss 目标及错误技能引用都会在开战前失败。

## 可试玩入口

主战斗场景顶端提供三套 Build 与八名正式敌人的战前军令选择。赵烈、周靖、韩月分别使用身份回归 Seed 15、10、4；点击“按军令开战”会创建新的 CombatRequest，不把战斗状态写入 Campaign 或存档。严成降至半血以下时，战场反馈会明确提示【死守孤城】已经发动。

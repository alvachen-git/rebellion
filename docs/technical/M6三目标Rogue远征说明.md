# M6 三目标 Rogue 远征说明

## 1. 玩家流程

M6-04 的可玩闭环为：

`主城 → 三目标选择 → 出征整备 → 9层随机路线 → 战斗/事件/商人/奖励 → Boss → 待结算 → 主城`

河源县、石门山、临泽市同时开放且无固定顺序。`available_expeditions()` 从内容注册表与 Campaign 领地实例计算可用状态；已控制目标不可再次整备。三地全部控制后返回 `all_captured=true`，UI 显示“三地平定”，Campaign 仍处于可继续的主城状态。

## 2. 生成器 v2（M6-04历史实现）

`ExpeditionMapGenerator` 保留 v1 固定河源图，并新增 v2 分层 DAG：第0层起点、第8层 Boss；第1/3/7层普通战，第5层精英战；第2/4/6层从事件、商人、补给、物品和卡牌奖励中生成2～3个节点。第1层固定两个入口，确保起点遵守最多两条出边；其他节点各有1～2条出边、无死路且全部可达 Boss。

随机流按拓扑、节点类型、敌人和事件分别派生。奖励卡池属于遭遇解析配置，不参与地图随机流。存档冻结 `generator_version`、`map_seed` 与 `map_signature`；载入时从当前内容重建地图并严格比对签名、路线集合和流水。

V4 活动河源迁移时补 `generator_version=1` 与 `map_signature=legacy-v1`。协调器使用隐藏的 `prototype_heyuan_encounters.json` 和原固定图恢复该趟远征，不能用 v2 替换。

M6-04E 后，新远征已切换到生成器 v3；v2 只用于恢复已有活动远征。当前三线规则、情报、民望与事件库详见 `M6三线地图民望与事件库说明.md`。

## 3. 遭遇与选择事务

`ExpeditionEncounterResolver` 从 `prototype_rogue_expeditions.json` 冻结事件、商人、物品或卡牌选择。风险事件在检查点创建时用事件 Seed 决定结果；玩家载入后看到的是同一份不可变选择，不会刷新。

`pending_encounter`、`choice_action_ids`、`choice_history` 与 `pending_node_resolution` 共同描述选择检查点。选择效果、路线完成和解析流水一次提交；重复 `action_id` 返回幂等成功。抵达选择、选择结算、领取奖励和物品使用均自动保存，保存失败由 `GameFlowCoordinator` 恢复操作前的完整 Envelope。

商人可交易一件物品、一张临时牌或补给服务，也可袭击护卫或离开。交易只读写 `unbanked_loot`；主城资源不能在远征中直接消费。

## 4. 临时牌、永久候选与物品

出征冻结“基础牌组 + 武将全部专属牌”。途中卡牌效果只向冻结牌组追加：第3层战后固定临时三选一，第5层精英战后包含一个永久候选，第6层节点以50%概率提供额外临时三选一。

永久候选立即加入本趟牌组，但写入 `pending_card_unlocks`，每趟最多一个。成功结算才加入 Campaign 公共牌库；已拥有卡转化为25军学。撤退或失败不提交候选，且所有 `temporary_cards` 随远征结束消失。

临时物品栏最多3格，允许重复。行军干粮、振军战鼓、火油、斥候令牌分别复用恢复兵力、恢复士气、下一战攻击与地图揭示规则。物品只可在地图或待选择阶段使用，使用动作同样以稳定 ID 幂等并自动保存。

## 5. 叛乱与长期结算

Campaign 的 `rebellion_state` 保存0～100数值、60点围剿预告阈值、幂等流水和历史。攻下一地在成功结算时+30；袭商+8、部分事件±5先累积在 `pending_rebellion_delta`，不因撤退或失败取消。

普通奖励、事件收益、交易与 Boss 奖励全部先进入未入库战利品，只有成功入库。真实兵损、武将死亡/重伤及叛乱变化继续由最终结算事务提交。达到60只设置 `suppression_forecast=true`，不会创建围剿、修改敌人或推进新世界阶段。

## 6. UI 与测试入口

`GameShell` 增加三目标页、通用按层地图、事件/商人/奖励面板与常驻物品栏、临时牌数、未入库资源、民望和本趟叛乱摘要。v3 地图 UI 只使用 `visible_nodes` 公开的节点类别；具体敌人、事件标题和选择结果仍按详情权限隐藏。

专项测试入口：

```bash
godot --headless --path . --script tests/run_m6_rogue_tests.gd
```

完整串行回归入口：

```bash
scripts/ci/run_all_tests.sh /tmp/dynasty-rebellion-m6-04-full
```

M6-04E 完成后的 Rogue 专项为2092通过、0失败；UI专项74通过、0失败；23套串行全量回归为3917通过、0失败。每组均严格扫描 `SCRIPT ERROR`、`Parse Error`、`Invalid call`、`TEST FAIL:`、未处理异常与非白名单 `ERROR:`；结果为空。Godot 4.6.1 macOS 系统证书查询警告仅由测试脚本按精确文本白名单过滤。

测试覆盖200个 Seed × 三地的v3拓扑约束与确定性、v1/v2活动远征恢复、36事件契约、选择/奖励检查点、民望成功/撤退/失败结算、保存失败回滚、永久奖励、三地顺序完成及真实 CombatController。三线地图另以真实 Godot 图形窗口在1600×900和1280×720完成截图复核，未发现裁切、重叠或不可达操作。

## 7. 明确未实现

本批不实现朝廷围剿、守城、扫荡、叛乱自然衰减、正式装备、远征中删换/升级牌、武将专属牌自由选择或第四处远征。所有新增经济、敌人数值、事件结果与领地收入继续标记为【原型暂定】，等待 M6-05 真人试玩。

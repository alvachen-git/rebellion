# M3 内容契约说明

## 当前状态

M3-02A 内容层、M3-02B 三武将机制、M3-03 敌人批次与 M3-04 严成 Boss 均已完成本地实现。主场景默认使用赵烈对官军巡检，并可直接切换三套正式 Build、五种普通敌人、两名精英和严成 Boss。

## 已落地内容

- `data/content/cards/m3/`：19张基础形态卡牌，每张包含两个结构化升级分支。
- `data/content/talents/`：赵烈【陷阵】、周靖【铁壁】、韩月【穿阵】、高武【军纪严整】、贺巍【黑甲】、严成【死守孤城】。
- `data/content/generals/`：三名武将的基础属性、战斗换算、兵种构成和20张初始牌组。
- `data/content/enemies/`：五种普通敌人、两名精英、严成 Boss 及保留的开发基准敌人。
- `ContentRegistry`：加载并校验 Card、Talent、General、Enemy，检查稳定 ID、引用、天赋归属、Intent 类型、技能条件/效果、专属牌归属与复制上限。

## 契约边界

- 非开发卡必须提供完整说明和两个不同升级分支。
- 初始牌组引用必须存在，专属牌不得跨武将使用，也不得超过 `copy_limit`。
- 武将/敌人与天赋必须双向匹配，兵种比例之和必须为1；一个天赋只能归属武将或敌人之一。
- 正式敌人必须提供层级、完整展示文本、至少一个技能，以及唯一技能 ID、可识别 Intent、非负冷却与结构化条件/效果；普通随机候选权重必须为正，`queued_only` 强制技能权重必须为0且不会进入随机池。
- Boss 必须提供结构化 `boss_modifier_rules`；强制行动效果及战略削弱所引用的技能必须属于同一 Boss，阶段比例必须严格处于0与1之间。
- M3 新效果类型已经接入运行逻辑；预计值会按实际效果顺序模拟天赋破防、卡牌破防、护甲转化与逐段倍率。

## 自动化入口

`tests/run_m3_content_tests.gd` 覆盖19张牌的完整字段、可满足使用路径、核心效果标识、升级分支，以及三武将/天赋引用和失败路径。`scripts/ci/run_all_tests.sh` 已串联该套件。

`tests/run_m3_runtime_tests.gd` 覆盖三天赋的回合边界、反击、两类护甲伤害、箭阵标签匹配、兵力恢复上限、天赋归属失败路径，以及三名武将的固定 Seed 身份回合。

`tests/run_m3_enemy_tests.gd` 覆盖七名非 Boss 敌人的完整内容契约、固定 Seed Intent、攻击/防守/扰乱/恢复的真实执行、高武每回合边界、贺巍初始护甲边界、软克制和错误天赋归属。

`tests/run_m3_boss_tests.gd` 覆盖严成内容契约、确定性 Intent、50%边界与单次阶段触发、立即护甲、当前 Intent 保持、先进先出强制队列、援军伤害/士气、恢复、三项独立纯修正、组合输入和失败契约。M3-04 完整串行回归为617通过、0失败。

`tests/run_m3_balance_tests.gd` 覆盖固定策略输入失败、20回合边界、同 Seed 完整统计行复现、480场矩阵契约、两种胜利路径和三武将天赋身份。M3-05 加入统计套件后的完整串行回归为633通过、0失败；回合目标偏离作为报告结果保留，不通过修改断言掩盖。

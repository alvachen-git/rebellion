# M3 内容契约说明

## 当前状态

M3-02A 已完成内容层落地，但新增的天赋、反击、护甲转伤害与箭阵强化尚未接入 CombatController。当前主场景继续使用开发牌组，避免把“可加载”误当作“已可玩”。

## 已落地内容

- `data/content/cards/m3/`：19张基础形态卡牌，每张包含两个结构化升级分支。
- `data/content/talents/`：赵烈【陷阵】、周靖【铁壁】、韩月【穿阵】。
- `data/content/generals/`：三名武将的基础属性、战斗换算、兵种构成和20张初始牌组。
- `ContentRegistry`：加载并校验 Card、Talent、General，检查稳定 ID、引用、专属牌归属与复制上限。

## 契约边界

- 非开发卡必须提供完整说明和两个不同升级分支。
- 初始牌组引用必须存在，专属牌不得跨武将使用，也不得超过 `copy_limit`。
- 武将与天赋必须双向匹配，兵种比例之和必须为1。
- M3 新效果类型只在内容契约中登记；运行逻辑、预计值和战斗日志将在 M3-02B 一起实现，避免预览与真实结算分叉。

## 自动化入口

`tests/run_m3_content_tests.gd` 覆盖19张牌的完整字段、可满足使用路径、核心效果标识、升级分支，以及三武将/天赋引用和失败路径。`scripts/ci/run_all_tests.sh` 已串联该套件。

# M6-03A 军议堂与共用基础牌组说明

## 1. 交付结果

长期牌组已从“每名武将一套固定20张”调整为：

`势力共用公共基础牌组（15～25张） + 所选武将全部已解锁专属牌 = 本次冻结出战牌组`

本批新增主城地点“军议堂 · 牌组编排”，并把出征整备改为展示上述合成关系。M3 的三套20张 `starting_deck` 仍用于内容契约和独立战斗调试，不再写入 Campaign 长期玩法状态。

## 2. 领域与应用边界

`CampaignState.base_loadout` 保存唯一的共用基础牌组，`loadout_system` 保存 action ID、历史、恢复标记和旧牌组审计快照。`set_base_loadout()` 只在 `main_city` 开放，并校验：

- 数量为15～25张；
- 只包含已解锁的公共牌；
- 卡牌 ID 必须存在；
- 每张牌不超过内容定义中的复制上限；
- 相同 action ID 重放不重复修改或写历史。

共用基础牌组不绑定某一武将，因此重伤或死亡不阻止玩家编辑。武将死亡仍由既有长期规则清空该武将的天赋和专属牌，并禁止其出征，不改变基础牌组。

`DeploymentAssembler` 先保持基础牌组顺序，再按武将实例中 `unlocked_exclusive_cards` 的稳定顺序各追加一次。`expedition_readiness()` 和出征快照同时返回 `base_deck`、`exclusive_cards`、`deck`；CombatRequest、永久升级覆盖和真实 CombatController 全部使用合成后的 `deck`。

## 3. 新档与 Save V4

新存档使用 Save V4 和 `content_version=0.6.1-m6-deck-editor`。`prototype_campaign_bootstrap.json` 集中配置初始基础牌组：当前15种初始解锁公共牌按研究目录顺序各1张；【追亡逐北】仍锁定。15～25张限制集中保存在 `prototype_deployment_rules.json`，均为【原型暂定】。

V1/V2 依次迁移至 V3，再进入 V4；V3 的 `general_loadouts` 被移入 `loadout_system.legacy_general_loadouts`，玩法字段改为尚未恢复的空 `base_loadout`。迁移保持原 `content_version`，且不会擅自选择任何一名武将的旧牌组。

回到主城后，玩家必须显式执行 `recover_legacy_base_loadout()`：仅补授实际缺失的15种原型公共牌，写入通用基础牌组，并记录按武将稳定排序的旧牌组张数/不同牌数摘要。同一恢复 action ID 幂等。活动远征不会被打断，仍使用出征时已经冻结的旧牌组；恢复界面继续写入手动槽1，不覆盖原自动档。

内容引用校验覆盖基础牌组、远征冻结牌组和战斗卡牌覆盖。旧 `legacy_general_loadouts` 只做结构与审计校验，不参与当前内容引用或玩法。

## 4. 军议堂界面

军议堂采用“军令簿”式三段工作区：左侧为当前基础牌组，中间为势力公共牌库，右侧为卡牌详情和赵烈、周靖、韩月的合成预览。基础牌组是主工作面，公共牌库是次级列表，朱砂色只用于合法确认。

编辑发生在本地草稿中：可暂时低于15张，但确认会禁用并解释缺少数量；25张或单卡复制上限时禁止继续添加；锁定牌可见但禁用并标注军学未解锁；放弃返回会丢弃草稿。确认后调用 `set_base_loadout()` 并回主城，不增加自动保存事件。

出征整备页明确显示“基础牌组 + 专属牌 = 出战牌组”，切换武将只改变专属牌和最终张数。界面不重算卡牌效果，卡名、费用、稀有度、效果、复制上限和永久升级分支都来自应用快照与内容注册表。

## 5. 验收证据

`tests/run_m6_deck_editor_tests.gd` 覆盖15/25张合法边界、14/26张、锁定/专属/未知牌、复制上限、三武将合成、死亡隔离、真实 CombatController、V3审计迁移、活动远征旧牌组冻结，以及军议堂草稿/取消/确认/手动保存/重载和出征切将预览，共69项断言，结果为69通过、0失败。

包括本专项在内的22组串行回归共1791通过、0失败。严格扫描 `SCRIPT ERROR`、`Parse Error`、`Invalid call`、`TEST FAIL:` 和非白名单 `ERROR:`，结果为空。Godot 4.6.1 macOS CA 证书查询噪声由测试脚本按精确两行白名单移除。

军议堂与出征整备均以真实 Godot 图形窗口在1600×900和1280×720进行截图复核：三栏内容、滚动区域、合成说明和底部确认操作无裁切、重叠或不可达。

## 6. 后续边界

M6-03A 只证明构筑规则、保存恢复和真实交互成立，不证明当前15张起始牌组、卡牌复制上限或三名武将的 Build 已达到最终平衡。下一批 M6-03B 才组织真人12问试玩；专属牌选择、远征中构筑、新卡、新武将、第二远征和正式美术均不在本批范围。

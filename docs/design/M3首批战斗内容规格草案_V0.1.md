## 0. 文档状态

- 状态：**四项玩法边界已于 2026-09-01 获玩家确认**，可作为 M3 实现依据；数值仍为可测试调整的原型参数。
- 规则来源：V0.4 已锁定机制、D-003 与 D-006。
- 本文所有费用、威力、护甲、士气、权重、冷却、初始属性与升级数值均为【原型暂定】。
- 本批只服务 Vertical Slice 的三种 Build；不扩展远征拿牌、复杂装备、完整 39 张卡池或玩家角色出战。
- M3-02A 已按本草案落地内容契约；后续依次完成运行机制、身份战、敌人与回合统计。

## 1. 本轮要证明什么

| 武将 | 核心节奏 | 主要胜法 | 明确弱点 |
|---|---|---|---|
| 赵烈 | 降低敌军士气 → 低费连击 → 第三张攻击返行动力 → 爆发 | 兵力击破，也可由士气铺垫完成溃败 | 启动前偏弱；高士气恢复敌人会拖慢连锁 |
| 周靖 | 建立护甲 → 承受攻击 → 反击/护甲转伤害 | 以低损耗兵力击破 | 扰乱和恢复型敌人会降低护甲的输出效率 |
| 韩月 | 连续破防 → 多段弓弩攻击 → 穿阵爆发 | 兵力击破，尤其针对高防目标 | 面对低防抢攻敌人时准备回合价值较低 |

验收时不以单卡强度作为成功标准，而看三套牌是否都有清晰的“准备 → 启动 → 爆发”核心回合。

## 2. 内容 ID 与字段约定

- 公共牌：`card.public.<体系>.<英文名>`。
- 专属牌：`card.general.<武将>.<英文名>`。
- 武将：`general.<英文名>`；天赋：`talent.<武将>.<英文名>`。
- 敌人：`enemy.<层级>.<英文名>`；技能：`skill.<敌人>.<英文名>`。
- `owner_scope=public` 的牌进入势力公共牌库；`owner_scope=general:<id>` 的牌只属于指定武将。
- `基础/高级/稀有/秘策` 的单套复制上限分别为 `3/2/1/1`。
- 所有牌都必须有名称、费用、标签、条件、顺序明确的效果、说明文本和两个升级分支；M3 只实现基础形态，升级选择留到 M5 接入。

### 7.3 三种战略削弱输入

Combat 只消费由 M4 传入的 `boss_modifiers`，不自行判断地图节点是否完成。

| 输入 | 独立效果【原型暂定】 | 不得影响 |
|---|---|---|
| `armory_destroyed=true` | 初始防御42→30；坚城固守110→75；死守孤城和固守城池的200护甲→140 | 不改变士气、恢复或援军技能 |

三个修正允许测试时任意组合，但每个修正必须由独立纯函数应用，禁止共享可变的 Boss 定义数据。

## 8. M3 所需的受控内核扩展

现有 M1 已覆盖普通伤害、护甲、士气、抽牌、行动力、降防、状态、多段、条件嵌套与自身士气消耗。M3 只新增下列内容需要的最小扩展，不建立通用脚本语言：

1. `GeneralDefinition` / `TalentDefinition` 加载、引用与唯一 ID 校验。
2. 三个明确天赋触发点：第N张攻击牌、每回合首次卡牌护甲、每回合首张指定标签攻击。
3. `DealDamageFromArmor` 与 `ConvertArmorToDamage`，预计值与真实结算必须共用同一计算器。
4. 【守势反击】的受击后触发，以及【箭阵待发】对下一张指定标签攻击的逐段倍率与消耗。
5. `RestoreTroops`，恢复量不得超过开战时最大兵力；补充敌方技能需要的 `OwnMoraleAtMost` 与 `OwnTroopRatioAtMost` 两个直接条件。
6. Boss 的强制下一 Intent 队列，以及精英对士气效果/Intent 候选池的受控拦截。
7. 战斗日志补充天赋触发、状态消耗、恢复、护甲转伤害、强制 Intent 与 Boss 修正事件。

不在本轮增加速度、暴击、闪避、独立兵种单位、复杂目标选择或敌方完整牌组。

## 9. 分批实现与验收顺序

1. **M3-01 规格确认**：确认本文的身份机制、初始牌组、敌人考题与暂定数值方向。
2. **M3-02A 内容契约**：加入 General/Talent schema、19张基础卡定义和引用校验；每张牌至少一条可用性测试。
3. **M3-02B 三武将身份**：实现三个天赋、三套20张牌组和固定 Seed 核心回合；每个天赋有正常、边界与每回合上限测试。
4. **M3-03 敌人批次**：实现五普通与两精英；逐个验证公开 Intent 和软克制行为。
5. **M3-04 Boss 批次**：实现阶段强制技能、恢复、援军队列和三种互不串状态的战略削弱接口。
6. **M3-05 统计验收**：固定策略脚本统计普通3～5回合、精英4～7回合、Boss 6～10回合；偏离时先报告，不静默调参。

## 10. 已确认的四个边界

1. 三名武将的玩法身份和20张初始牌组方向是否符合预期。
2. 赵烈以兵力连击为主、士气溃败为辅；是否符合“低士气斩杀”的侧重点。
3. 周靖的护甲既可触发反击，也可主动转为伤害；是否接受这两种出口并存。
4. 韩月的防御降低在单场战斗内持续生效；是否接受其作为长期铺垫，而不是只持续一回合。

以上四项均已确认并允许进入 M3 内容实现；这不代表锁死本文全部暂定数值，后续仍以固定 Seed 身份战和回合统计进行可追溯调优。

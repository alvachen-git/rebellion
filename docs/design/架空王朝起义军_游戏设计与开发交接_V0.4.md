# 架空王朝起义军：游戏设计与开发交接文档 V0.4

> 文档用途：将当前已经讨论并确定的游戏设计，整理成可直接交给 Codex 阅读的第一版开发基线。本文优先描述“已锁定规则、可测试原型参数、第一阶段 Vertical Slice 范围与推荐代码拆分”。
>
> 核心原则：**人物 + 势力长期成长 + 长期卡牌 Build + 约30分钟 Roguelike 路线远征。** 主城只负责局内长期成长，不做复杂多城经营。

## 0. 状态说明

本文使用三种状态：

- **【锁定】**：当前设计已经确定，后续代码规划不得擅自改变；若技术上有冲突，应先提出问题。
- **【原型暂定】**：用于第一轮可玩原型的参数或公式，可以通过测试调整。
- **【待设计】**：当前尚未展开，先预留接口，不要过早实现复杂功能。

---

# 1. 游戏定位

## 1.1 类型

架空王朝题材的长期战役游戏，主要由以下四部分构成：

1. 武将长期养成与永久死亡。
2. 势力公共牌库的长期 Build。
3. 单名武将率军进行约30分钟的节点式远征。
4. 主城作为长期成长 Hub，将远征成果转换成永久战力。

不以复杂城市经营、大地图即时 SLG 或多个城市逐城治理为核心。

## 1.2 核心玩家幻想

玩家从弱小起义军开始，逐步拥有名将、精锐军队、成熟牌组和越来越大的势力版图，最终挑战王朝核心力量。

核心爽点有两个：

- **成长爽感**：从弱小起义军成长为强大政权，武将、军队、公共牌库和主城功能越来越完整。
- **卡牌套路爆发**：玩家花整场游戏构筑一套长期 Build，在满足条件后通过抽牌、0费、返行动力、破甲、士气门槛、护甲转伤害等形成强力连锁。

设计上允许玩家通过合理长期投入构筑出非常强、甚至接近“打破规则”的组合，不追求所有 Build 严格同强度。

# 2. 整体游戏循环

## 2.1 主循环【锁定】

远征 → 路线选择与连续战斗 → 完成任务 → 战利品正式入库 → 主城长期成长 → 武将/军队/牌组整备 → 选择下一远征目标 → 再次远征。

## 2.2 单次远征长度【锁定】

- 标准单次远征目标时长：**约30分钟**。
- 普通战：约3～5回合。
- 精英战：约4～7回合。
- Boss：约6～10回合。
- 一次标准远征约12～16个节点，其中约6～8场战斗。

## 2.3 Build 的时间尺度【锁定】

牌组 Build 发生在**整场游戏/整个存档**中，而不是每次远征从零构筑。

远征途中不采用《杀戮尖塔》式“战后3选1卡牌、删牌、临时构筑主牌组”。远征可以带回兵法残篇、资源等，回到主城后研究并永久解锁卡牌。

# 3. 玩家与武将

## 3.1 玩家角色【锁定】

- 玩家开局可自创角色。
- 玩家角色本身是可出战武将。
- **没有继承制。**
- 玩家角色死亡 → **立即 Game Over**。

玩家亲征未来可以拥有额外收益或领袖特色，但不得通过“继承人”规避死亡风险。

## 3.2 武将基础属性【锁定】

只保留三个：

| 属性 | 核心作用 |
|---|---|
| 武勇 | 少量影响战斗攻击能力 |
| 统率 | 主要影响最大带兵数量，可少量参与基础防御等换算 |
| 政务 | 影响主城/资源/非战斗用途 |

不要增加速度、暴击、命中、闪避、谋略、体质等大量传统 RPG 基础属性。武将差异的核心不是数值，而是：**核心天赋 + 成长天赋 + 专属卡。**

## 3.3 武将天赋【锁定方向】

- 每名重要武将拥有一个固定核心天赋，决定主要玩法身份。
- 成长过程中只做少量关键二选一，不做大型天赋树。
- 同一个武将可以因为成长分支不同形成不同 Build 方向。

## 3.4 专属卡【锁定】

- 重要武将约拥有3～5张专属卡。
- 专属卡只属于对应武将，不进入势力公共牌库。
- **武将死亡后，其专属卡与天赋永久消失。**
- 专属卡不允许由其他武将继承。

这意味着一个培养很久的武将死亡，玩家失去的是完整玩法体系，而不是一个高数值角色。

# 4. 永久死亡、重伤与撤退

## 4.1 兵力归零【锁定】

兵力代表武将率领军队的生存状态。

- 兵力归零 → 军队被歼灭。
- 该武将 **100%死亡**。
- 如果是玩家自创角色 → Game Over。

## 4.2 士气归零【锁定】

士气归零代表军队溃败：

- 20%概率：武将死亡。
- 80%概率：武将重伤。
- 重伤武将在若干势力周期内不能出征。

如果是玩家角色：20%死亡即 Game Over；80%重伤则游戏继续。

## 4.3 战斗中主动撤退【锁定】

玩家可以在战斗中主动撤军：

- 武将确保生还。
- 当前远征立即失败。
- 本次远征此前获得的**全部未入库奖励丢失**。
- 已经产生的兵力损失不会恢复。
- 可附加一定撤退伤亡或其他资源惩罚，具体数值属于原型平衡项。

## 4.4 远征不存在安全撤离点【锁定】

地图中**不设置安全撤离节点**。一旦出征，正常情况下必须完成任务才能将战利品带回。

# 5. 战斗表现与军队抽象

## 5.1 战斗方案【锁定】

采用简化方案：**武将 VS 武将**。

玩家不会在战斗中直接操控步兵、弓兵、骑兵等独立单位。每名武将代表其率领的一整支军队。

战斗 UI 核心只展示：

- 武将
- 兵力
- 攻击
- 防御
- 士气
- 护甲
- 行动力
- 当前兵种构成
- 当前状态/卡牌条件

## 5.2 兵种构成【锁定】

兵种不独立上场，只产生两类影响：

1. 影响开战时基础攻击、防御、士气等初始值。
2. 作为某些卡牌的使用门槛。

示例：

- 骑兵≥20%：可使用【骑兵突击】。
- 骑兵≥50%：可使用强力纯骑兵牌。
- 步兵≥60%：可使用【坚壁】。
- 弓兵≥40%：可使用高级箭雨类牌。

单场战斗中卡牌资格按**开战时军队构成**锁定；不会因为战斗中兵力损失而突然失去兵种门槛资格。

## 5.3 势力军队池【锁定方向】

军队属于势力统一库存，而非武将永久私人部曲。

出征时从军队池配置给武将；战斗伤亡会从势力军队库存中真实扣除。伤亡按出征时兵种比例进行结算即可，不需要战斗中实时追踪每个兵种死亡人数。

# 6. 士气系统

## 6.1 士气定位【锁定】

士气范围暂定0～100。

**普通攻击和普通兵力伤害不会降低士气。**

士气高低本身也**不会**自动提供攻击、防御、命中等全局奖惩。

士气的作用只有：

1. 士气归零触发溃败。
2. 作为卡牌使用条件。
3. 作为卡牌强化条件。
4. 可通过卡牌恢复。
5. 某些强牌可以主动消耗自身士气换取爆发。

## 6.2 典型条件

- 我方士气≥70才能使用高士气强攻牌。
- 敌人士气≤40时骑兵突击获得额外伤害。
- 敌人士气≤20时使用士气斩杀牌。
- 某些牌消耗我方10～20士气换取抽牌、行动力或高伤害。

士气应当是一条**卡牌构筑轴**，而不是第二套被动属性系统。

# 7. 攻击、防御、护甲与伤害

本节属于【原型暂定】，用于第一轮代码与数值测试。

## 7.1 攻击

卡牌带有基础威力；实际攻击威力可暂按：

`攻击前伤害 = 卡牌基础威力 × (1 + 攻击属性 / 100)`

攻击属性主要来自武将武勇、兵种构成及少量长期成长。

## 7.2 防御

建议采用递减收益公式，避免100%免伤：

`防御后伤害 = 攻击前伤害 × 100 / (100 + 防御)`

防御最低暂定0，不使用负防御。额外易伤应单独作为卡牌状态处理。

## 7.3 护甲

- 护甲由卡牌在战斗中临时获得。
- 防御先参与减伤，再由护甲吸收最终伤害。
- 护甲通常在下一次己方回合开始时清空。
- 防御属性不额外放大护甲牌，避免防御收益双重膨胀。

## 7.4 伤害顺序

卡牌基础威力 → 攻击属性 → 卡牌条件增伤 → 敌方防御 → 护甲 → 最终扣除兵力。

UI 应直接显示预计实际伤害，玩家不需要心算底层公式。

# 8. 玩家回合与牌组规则

本节除特别标注外属于【原型暂定】。

- 每回合初始行动力：3。
- 每回合抽牌：5。
- 回合结束未使用手牌进入弃牌堆。
- 抽牌堆为空时洗回弃牌堆。
- 关键词【耗尽】：使用后本场战斗不再进入弃牌堆。
- 主城保存一套势力共用基础牌组，只含已解锁公共牌，原型下限15张、上限25张。
- 出征选定武将后，将该武将当前已解锁的全部专属卡自动追加到基础牌组；专属卡不占15～25张限制。

卡牌复制数量暂定：

| 稀有度 | 单套牌最大数量 |
|---|---:|
| 基础 | 3 |
| 高级 | 2 |
| 稀有 | 1 |
| 秘策 | 1 |

核心目标是让玩家思考出牌顺序并形成“准备 → 启动 → 爆发”的回合节奏。

# 9. 长期公共牌库

## 9.1 双层牌库【锁定】

卡牌分为：

- **势力公共牌库**：代表势力掌握的军事知识，符合条件的武将都可编入。
- **武将专属卡**：只属于对应武将。

## 9.2 公共卡获取【锁定方向】

公共卡不是远征途中即时随机塞进牌组，而是通过长期成长获得：

- 主城军学研究
- 远征带回兵法残卷
- Boss/精英掉落研究线索
- 特殊事件
- 控制特定地区
- 特殊人物

例如远征带回《骑战残篇》 → 回主城投入军学与银两研究 → 永久解锁【追亡逐北】。

## 9.3 公共卡升级【锁定】

重要公共卡最多进行一次重大升级，通常为二选一分支。

**一旦选择，本局永久锁定，不能反悔、重置或洗点。**

升级应改变 Build 方向，而不是简单“伤害+10”。示例：

- 【骑兵突击·疾袭】：费用1→0，但威力下降。
- 【骑兵突击·破军】：费用不变，对低士气敌人增伤显著提高。

因此不同存档会自然形成不同的势力军学风格。

# 10. 第一批五类 Build

## 10.1 骑兵连击 / 低士气斩杀

降低敌人士气 → 进入≤40区间 → 骑兵牌强化 → 0费/返行动力/抽牌 → 一回合连续攻击。

主要特色：发动机型爆发。弱点是需要前置铺垫，且对高士气和士气恢复敌人较慢。

## 10.2 军心瓦解 / 溃败流

不追求杀完兵力，集中降低敌人士气并阻止恢复，最后士气归零直接结束战斗。

主要克制高兵力、高防御、低士气敌人。

## 10.3 坚阵反击流

获得大量护甲 → 吸收敌人攻击 → 触发反击 → 将剩余护甲转化为伤害。

主要特色：护甲既是防御，也是输出资源。

## 10.4 弓弩破甲流

多段攻击与破甲 → 将高防敌人防御打低 → 箭雨/穿甲齐射爆发。

主要特色：前期准备，后期高频多段伤害。

## 10.5 高士气决战流

维持高士气 → 使用高士气限定强牌 → 主动消耗士气换取爆发 → 再通过鼓舞恢复。

主要特色：把己方士气当作可管理、可花费的战斗资源。

下面是已规划的内容方向。第一阶段代码原型不需要一次性全部实现。

猛攻、坚守、鼓舞、重整旗鼓、临阵换令、蓄势、稳步推进、整军备战。

# 12. 三名 Vertical Slice 测试武将

数值属于【原型暂定】，机制定位优先。

## 12.1 赵烈：骑兵低士气连击

- 武勇84 / 统率72 / 政务24。
- 核心天赋【陷阵】：每回合打出第3张攻击牌时获得1行动力，每回合最多一次。
- 专属卡方向：独胆破阵、阵前叫战、穷追猛打、舍命强攻。
- 测试目标：低士气门槛、0费、返行动力、抽牌和骑兵条件能否形成明显连锁。

## 12.2 周靖：重步防御反击

- 武勇58 / 统率88 / 政务47。
- 核心天赋【铁壁】：每回合第一次通过卡牌获得护甲时额外获得40护甲。
- 专属卡方向：据阵而守、以寡拒众、后发制人、借势破敌。
- 测试目标：护甲能否同时承担生存和输出资源；面对高攻敌人是否形成反击爽点。

## 12.3 韩月：弓弩破甲

- 武勇70 / 统率80 / 政务61。
- 核心天赋【穿阵】：每回合第一张弓弩攻击牌额外使敌军防御-4。
- 专属卡方向：破阵连弩、鸣镝定阵、万箭穿心、封喉一箭。
- 测试目标：多段攻击、破甲和后续爆发是否构成清晰节奏。

# 13. 敌人设计原则

## 13.1 敌人不是完整抽牌者【锁定方向】

敌人使用：**技能池 + AI行动逻辑 + 下一步意图提示**。

不要让普通敌人也运行与玩家相同的完整抽牌/弃牌系统。这样更容易控制节奏和制作机制型 Boss。

## 13.2 Intent【锁定方向】

玩家在敌方行动前能看到下一步大致意图，例如：

- 强攻：预计造成兵力伤害。
- 防守：准备获得护甲。
- 扰乱：准备降低士气。
- 整军：恢复兵力/士气。
- 特殊：Boss技能。

敌人AI只能根据公开状态判断，不读取玩家未来抽牌。

## 13.3 敌人是“Build考题”【锁定原则】

不大量使用完全免疫某机制的硬克制。推荐软克制：减少士气损失、恢复较快、高防、压制我方士气等。

# 14. Vertical Slice 第一批敌人

## 14.1 普通敌人（5种）

1. **官军巡检**：标准基准敌人；攻击、防守、鼓舞、轻度士气攻击。
2. **乡勇团**：高兵力、低防御、低士气；用于验证士气溃败路线。
3. **城防兵**：高防御和护甲；用于验证破甲。
4. **弩军队**：高攻击、低防御；用于验证防御/反击与抢攻。
5. **督战队**：主动打我方士气并自我恢复；用于验证高士气 Build。

## 14.2 精英敌人（2种）

### 河源县都尉·高武

天赋【军纪严整】：每回合第一次受到的士气降低效果减半。同回合后续士气攻击正常生效。

目的：不是免疫士气流，而是逼士气玩家在一个回合内形成 Combo。

### 黑甲校尉·贺巍

天赋【黑甲】：开战获得大量护甲；护甲被完全打穿后下一回合不使用防御技能。

目的：鼓励玩家创造“破甲/破盾后的爆发窗口”。

---

# 15. 第一座县城 Boss：严成

Boss定位：守城型综合考验。Boss本身不是单纯血厚，而是与远征路线选择联动。

## 15.1 原型基础值【原型暂定】

- 兵力1750
- 攻击30
- 防御42
- 士气75

## 15.2 核心天赋

【死守孤城】：第一次兵力降至50%以下时立即获得200护甲；下一回合必定使用【固守城池】。每战一次。

## 15.3 技能池

- 守军齐射：兵力攻击。
- 坚城固守：获得护甲。
- 镇压军心：降低玩家士气。
- 据城整军：恢复兵力与士气。
- 求援烽火：准备下一回合援军夹击。
- 援军夹击：高伤并降低玩家士气。
- 固守城池：50%兵力阶段触发的特殊防守。

## 15.4 Boss 与地图据点联动【锁定方向】

- 破坏军械库：严成防御42→30，护甲技能也削弱。
- 摧毁烽火台：严成初始士气75→55，并移除求援/援军技能。
- 烧毁粮仓：移除【据城整军】，Boss无法恢复兵力与士气。

地图结构应使玩家通常无法把所有战略据点都处理掉，必须根据自己的长期 Build 选择最重要的一项。

---

# 16. 远征地图

## 16.1 基本结构【锁定】

- 节点式分叉地图。
- 玩家只能向前推进，不允许回到已经走过的节点。
- 地图可有部分迷雾/未知节点。
- 不存在安全撤离点。

节点第一版包括：

1. 普通战
2. 精英战
3. 随机事件
4. 补给/营地
5. 情报
6. 军事据点
7. 战利品
8. Boss/任务目标

## 16.2 战利品袋【锁定】

远征中获得的粮食、银两、军学、特殊资源、兵法残篇等全部进入“本次战利品”，在任务成功前均属于**未入库**状态。

完成目标 → 全部正式入库。

主动撤退/任务失败 → 按规则丢失未入库奖励。

## 16.3 远征临时状态

可以存在少量远征级 Buff，例如下一场初始士气+10、下一战攻击+10、揭开地图节点等；远征结束全部清除。它们不改变长期牌组 Build。

# 17. 第一场完整大型远征：《攻取河源县》

目标：击败河源县守将严成并占领县城。

## 17.1 第一段三条战略路线

### 官道线

战斗最多，最终可破坏**军械库**，降低 Boss 防御。适合直接输出/弓弩/连击 Build。

### 村野线

事件较多，最终可破坏**烽火台**，降低 Boss 初始士气并取消援军。适合士气流与低士气骑兵流。

### 粮道线

资源与消耗型路线，最终可烧毁**粮仓**，移除 Boss 恢复技能。适合防反与消耗 Build。

三条路线汇合后进入精英战。

## 17.2 后半段选择

后半段再提供不同性质选择：

- 情报路线：揭示 Boss 属性、天赋、关键技能。
- 补给路线：恢复兵力或士气。
- 财富路线：高奖励但增加额外战斗风险，不帮助 Boss 战。

最终必须进入县城 Boss 战；无安全撤离。

## 17.3 胜利里程碑

攻下河源县后：

- 玩家第一次真正拥有领地。
- 主城成长阶段提升。
- 开放更高级军学、兵种或招贤功能。
- 河源县开始提供周期性资源收入。

---

# 18. 主城成长系统

## 18.1 定义【锁定】

“主城”不是传统城镇经营，而是**整场游戏唯一的长期成长 Hub**。

即使未来玩家占领数十座城市，也不会为每座城市生成独立建设与经营界面。

## 18.2 主城主要入口

第一版可压缩为：

1. **整军**：兵力库存、补兵、训练兵种、出征军队配置。
2. **军学**：公共卡解锁、研究、不可逆升级。
3. **武将**：属性、等级、天赋、专属卡、伤势。
4. **军议堂**：编排势力共用的15～25张公共基础牌组，并预览各武将自动追加专属牌后的出战牌组。
5. **招贤**：候选武将和特殊人才。
6. **势力**：领地、周期收入、势力阶段。
7. **出征**：选择目标、武将与兵种构成，冻结“基础牌组 + 所选武将专属牌”。

医馆等功能可以整合进武将页面，不必为每个功能单独做复杂系统。

## 18.3 主城视觉成长

玩法简单，但画面应随势力阶段明显成长：破旧山寨 → 义军大营 → 都督府/军府 → 王都。

视觉成长是长期成长爽感的重要表达，但第一阶段原型可以用静态占位界面。

---

# 19. 资源经济

## 19.1 四种主资源【锁定方向】

| 资源 | 主要用途 |
|---|---|
| 银两 | 训练军队、研究卡牌、招贤、主城功能等 |
| 粮食 | 出征、大规模补兵和部分事件 |
| 兵源 | 将人口转化为实际士兵，补充战斗伤亡 |
| 军学 | 解锁/升级势力公共卡牌 |

特殊资源少量存在，例如战马、精铁、药材、兵法残篇，但不把主资源栏做得很复杂。

## 19.2 兵种训练

兵源不能直接无成本转为高级兵种。

例如骑兵需要：兵源 + 银两 + 战马；高级重步兵需要兵源 + 银两 + 精铁。

高级兵种损失应具有明显长期成本。

## 19.3 资源经济原则

- 玩家应长期处于“资源不够把所有想做的事情同时完成”的状态，从而产生选择。
- 但基础远征不应因没粮食等原因彻底阻止玩家继续游戏。
- 高级资源主要限制高级 Build、精锐兵种和高价值成长，而不是限制基本游玩。

---

# 20. 势力周期与领地

## 20.1 势力周期【原型暂定】

完成一次主要远征后推进1个势力周期，并统一结算：

- 领地收入
- 重伤恢复
- 招贤刷新
- 世界阶段变化

不提供“在主城连续点下一天挂机收资源”的玩法。

## 20.2 其他城市【锁定】

其他城市只作为势力资产与长期收益来源：

- 银两
- 粮食
- 兵源
- 特殊资源
- 特殊战略效果

**其他城市不允许玩家逐城升级，不产生独立城市画面。**

例：

- 河源县：银两+180 / 粮食+260 / 兵源+60 / 精铁+8（原型数值）。
- 产马地：提高战马来源。
- 人口大县：提高兵源。
- 军事重镇：可能解锁某类军学研究条件。

这使“Build需要什么资源”能够反过来影响玩家未来扩张方向。

---

# 21. 武将成长

## 21.1 成长优先级

武将成长应优先体现为：

1. 新天赋/天赋分支
2. 解锁专属卡
3. 专属卡强化
4. 少量武勇/统率/政务成长

不要把主要成长做成每级攻击+3%、生命+5%。

## 21.2 原型等级节奏【原型暂定】

Vertical Slice 可先做 Lv1～Lv6：

- Lv1：初始
- Lv2：少量属性成长
- Lv3：天赋二选一
- Lv4：解锁专属卡
- Lv5：少量属性成长
- Lv6：第二次天赋二选一

升级速度不应快到一趟远征连续升多级。

## 21.3 招贤

普通候选武将可通过模板生成，但真正重要的稀有人物应通过 Boss 招降、特殊事件、剧情或精英敌将获得。

长期目标是让每个重要武将拥有真正独特的天赋和专属卡，而不是单纯更高数值。

---

# 22. 当前明确不做/不要过早做的系统

第一阶段明确不做：

- 多城市逐城经营
- 城市建筑Lv1/Lv2/Lv3循环
- 农田、商铺、生产链
- 复杂人口/治安/满意度
- 大型官职与文官系统
- 即时大地图军团移动
- 复杂装备锻造
- 兵种经验等级
- 暴击、命中、闪避等大量RPG属性
- 武将复杂关系网
- 每次远征从零卡组Build
- 敌人完全照搬玩家抽牌系统
- 频繁“免疫某Build”的硬克制

这些系统未来如果证明必要再加入，不应阻碍第一版核心循环验证。

# 23. Vertical Slice 第一阶段范围

第一阶段目标不是做完整游戏，而是证明：

**长期牌组 + 武将机制 + 兵种门槛 + 节点远征 + 主城永久成长** 是否真的形成“再打一趟”的动力。

建议范围：

- 玩家自创角色：先做基础占位版本即可。
- 测试武将：3名（赵烈、周靖、韩月）。
- 基础兵种：步兵、弓兵、骑兵。
- 第一批代码卡牌：约19张。
- 后续内容卡池规划：39张。
- 普通敌人：5种。
- 精英敌人：2种。
- Boss：严成1名。
- 完整远征：攻取河源县1张。
- 主城：整军、军学、武将、势力、出征的基础界面。
- 主资源：银两、粮食、兵源、军学。
- 领地：河源县至少1个可提供周期收入。
- 卡牌研究与不可逆升级。
- 武将重伤/死亡。
- 存档与读档。

# 24. 推荐给 Codex 的代码结构

本章属于开发建议，不是玩法规则。若现有项目架构已有成熟方案，应在不破坏现有代码的前提下映射。

## 24.1 原则：数据驱动

卡牌、武将、敌人、远征节点、领地、研究等内容不要硬编码在战斗 UI 或场景脚本里。

建议至少抽象以下“定义数据”：

- `CardDefinition`
- `CardEffectDefinition`
- `GeneralDefinition`
- `TalentDefinition`
- `EnemyDefinition`
- `EnemySkillDefinition`
- `ExpeditionDefinition`
- `ExpeditionNodeDefinition`
- `TerritoryDefinition`
- `ResearchDefinition`
- `ArmyTypeDefinition`

运行时则区分：

- `CampaignState`
- `GeneralInstance`
- `DeckInstance`
- `ArmyInventory`
- `ExpeditionRunState`
- `CombatState`

## 24.2 卡牌效果系统

第一版不要为每张卡写一个完全独立脚本。建议使用可组合效果：

- DealDamage
- GainArmor
- ModifyMorale
- DrawCards
- GainActionPoint
- ModifyDefense
- ApplyStatus
- ExhaustSelf
- ConditionalEffect
- RepeatAttack
- ConsumeOwnMorale

条件系统需要支持：

- 兵种比例门槛
- 我方/敌方士气阈值
- 当前护甲
- 本回合已打出攻击牌数量
- 本回合敌方已损失士气数量
- 敌方防御阈值
- 是否拥有某状态

这样后续39～100张牌可以主要通过数据组合，而不是无限新增特殊脚本。

## 24.3 战斗控制器

建议战斗状态机至少包含：

1. BattleSetup
2. PlayerTurnStart
3. PlayerAction
4. PlayerTurnEnd
5. EnemyIntentResolve
6. EnemyTurn
7. VictoryCheck
8. DefeatCheck
9. RetreatResolve
10. BattleResult

应支持调试模式直接指定武将、牌组、敌人和随机种子进入战斗。

## 24.4 敌人AI

第一版采用规则/权重AI即可：

- 根据公开兵力、士气、护甲、冷却判断技能权重。
- 能发现兵力斩杀或士气斩杀机会。
- 不读取玩家未来抽牌。
- Boss可根据50%兵力等阈值切换阶段。

## 24.5 远征控制器

需要保存：

- 当前节点
- 已走路线
- 当前武将状态
- 当前剩余兵力/士气
- 未入库战利品
- 本次远征临时Buff
- 已破坏的军事据点
- Boss受到的战略削弱

战斗之间武将的兵力和士气应保持连续，而护甲等单场状态清除。

## 24.6 主城/长期状态

`CampaignState` 至少保存：

- 四种主资源
- 特殊资源
- 已占领领地
- 军队库存
- 已招募武将及其成长状态
- 已解锁公共卡
- 公共卡不可逆升级分支
- 势力共用公共基础牌组
- 当前势力周期
- 主城阶段

## 24.7 存档

因为存在不可逆卡牌升级与永久死亡，必须从 Vertical Slice 阶段就支持可靠 Save/Load，并预留 `save_version` 进行后续数据迁移。

建议不要等完整游戏再补存档。

## 24.8 可重复调试

推荐战斗和地图随机过程使用可记录 Seed，便于：

- 复现卡牌Bug
- 平衡同一场战斗
- 比较Build
- 自动测试

# 26. Vertical Slice 验收问题

第一版原型完成后，不以“内容数量”为成功标准，而是回答下面问题：

1. 玩家是否会主动思考出牌顺序，而不是有攻击打攻击？
2. Build是否存在明确的“准备 → 启动 → 爆发”瞬间？
3. 赵烈、周靖、韩月是否像三种不同角色，而不是数值不同？
4. 士气击败与兵力击败是否都真实可行？
5. 兵种比例门槛是否增加Build深度，而非增加繁琐操作？
6. 普通敌人是否3～5回合即可解决？
7. 一次连续6～8场战斗的远征是否过于疲劳？
8. 军械库/烽火台/粮仓路线是否会因为玩家Build不同而产生不同最优选择？
9. “战利品全部可能丢失”是否制造足够风险感？
10. 永久死亡是否刺激，但没有导致玩家只敢永远藏最强武将？
11. 回主城后，研究/补兵/武将成长是否能产生“再打一趟”的动力？
12. 玩家看到一个新卡解锁条件时，是否会立刻想改变下一次远征目标？

只有这些问题基本成立后，才进入大规模内容生产与世界地图扩展。

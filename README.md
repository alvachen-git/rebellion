# 架空王朝起义军

长期战役制卡牌 Roguelike 的新项目工作区。

## 当前状态

- 当前阶段：M1 Headless 战斗内核完成，下一步进入 M2 最小战斗 UI
- 设计基线：V0.4，已归档到 `docs/design/`
- 技术基线：Godot 4.6.1，macOS/Windows 横屏桌面版，键鼠优先
- 代码状态：工程骨架、内容校验、固定 Seed、Save DTO、战斗状态机与 Headless 回归已建立
- 当前目标：按 M1～M7 逐阶段交付完整 Vertical Slice

## 核心产品定义

玩家在唯一主城中长期培养武将、军队和势力公共牌库，选择一名武将率军进入约 30 分钟的节点远征；战斗以兵力、士气、护甲、行动力和长期卡牌 Build 为核心，同时承担武将永久死亡与未入库战利品全部丢失的风险。

## 开发约束

1. V0.4 中的【锁定】规则不得由实现自行改写。
2. 【原型暂定】数值必须数据化，不写死在 UI 或流程脚本中。
3. 【待设计】内容只预留接口，不提前扩成完整系统。
4. 每个里程碑先满足自动化验收，再进入下一阶段。
5. 单场战斗、远征运行态、战役长期态严格分层。
